1) Selection.java i.e Selection Sort algorithm.

Technical explaination : In Selection sort what we basically do is select the first element in hand and then swap it instantly with the smaller element found in the iterations.

Steps I did :
1.Take Input for Array and Size.
2.write a selection sort function with Array and N as input
3.2 loops one for selection of the start element each time (i) another one for iteration (j=i)
4.in first loop we save the index of first element in a min variable.
5.in inner loop, we check if element at [j]< element at[min]
if yes, then store the j index in Min value

After that exit the loop so that swap can be done which is pretty basic.
